← HomeNEW WORK / OCTOBER 2026 · PROJECT FRONTIER

35 game assets.
One survival world.

Props, vehicles and tools for Project Frontier, my first-person survival game in Unity. Each one is shown textured and as clay geometry, rendered in Blender (Cycles).

Game assets in production, not final art: generated in Tripo from my reference sheets, then chosen and textured for the game’s worn survival look. Triangle counts are the full-detail mesh; lighter versions are made for the game.
